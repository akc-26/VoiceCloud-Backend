Corrected scope
1. Creator Pause / realtime authentication race
   - Shared awaited socket-authentication promise is now used by connection and realtime handlers.
   - Presence, room and reaction handlers no longer read socket identity before JWT verification completes.
   - Security remains fail-closed for missing/invalid tokens.

2. Creator /rooms broadcast controls UI
   - Clear Ready / On air / Paused control state.
   - Improved Go Live, Pause/Resume, End, microphone and Manage Live Room hierarchy/spacing.
   - Removed a hard-coded live-card shadow in favor of the Creator theme.

3. Creator schedule lifecycle + timezone
   - Creator-local date/time editing and canonical ISO instant submission.
   - Schedule cards expose create/start linked broadcast, edit date/time, pause/resume/end,
     start speaking/mute and Open Console where applicable.
   - scheduled_rooms.scheduledStartTime is migrated from timestamp to timestamptz.
   - Legacy values are interpreted as UTC during migration; browsers display the same instant in local time.

4. Creator room chat alignment
   - Own-message detection uses the durable authenticated creator userId even when the optional profile object is not hydrated.
   - Own messages render right; all other senders render left.

5. Host mute / speaker state
   - Existing provider-backed mute action remains authoritative.
   - Creator stage visibly reports muted speaker state.
   - Consumer speaker applies authoritative mute state, disables local microphone, and cannot re-enable it until unmuted.

6. Consumer emoji + broadcast pause/end realtime behavior
   - Reaction ACK now returns the authoritative reaction payload.
   - One reconnect-presence recovery/retry is performed if transport reconnect lost room membership.
   - ACK/socket duplicate reaction events are de-duplicated.
   - Pause immediately disables live interaction controls and local speaking.
   - End immediately closes RTC/realtime state, redirects to /rooms, and surfaces an ended-broadcast notice.

7. Consumer room chat page growth
   - Chat grid uses minmax(0,1fr), bounded viewport height, hidden outer overflow and internal vertical scrolling.

8. Paused-room interaction authority
   - Consumer chat/reactions/hand raise/speaker controls remain disabled when not LIVE.
   - Creator invite/approve/mute/stage actions remain disabled while paused.
   - Backend live-interaction authority remains enforced; no guard was weakened.
