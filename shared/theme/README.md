# Shared Theme Module (@shared/theme)

## Responsibility
Provides standardized UI design system tokens (colors, typography, spacing, border radiuses, breakpoints) ensuring consistent visual language across Admin Portal, Creator Studio, and Landing Website.

## Exported Entities
- `THEME_TOKENS`: Design system design token palette.

## Guidelines
- UI applications should derive CSS/Tailwind/MUI theme variables from `THEME_TOKENS`.
