# VC-WEB-PH06-R01 Manual QA

Use this checklist after `scripts\website\VC-WEB-PH06-ACCEPTANCE.cmd` passes. Because PH06 was intentionally built on untested R14, the checklist includes the R14 LiveKit join regression as part of the same acceptance cycle.

- [ ] **PH06-QA-001 — R14 LiveKit join regression:** start a real LiveKit broadcast, sign in as a separate normal website user, open the live room, and confirm the user joins without `Unable to load LiveKit browser SDK...`. Confirm subscribed host/speaker audio can play.
- [ ] **PH06-QA-002 — My Rooms:** sign in as an approved Host/Creator, open `/host/rooms`, and confirm only rooms owned by that account are listed. Confirm room status, present count, speaker count, Start/Pause/Resume/Open/End/Settings actions match the backend state.
- [ ] **PH06-QA-003 — Host authorization:** sign in as an account without approved Host status and open `/host/rooms`. Confirm creation/broadcast controls are not exposed as successful local behavior and the backend-authoritative host-status message is shown.
- [ ] **PH06-QA-004 — Create Room:** create a room from `/host/rooms/create` with title, description, category/language and at least one access restriction. Return to My Rooms and confirm the persisted room appears after reload.
- [ ] **PH06-QA-005 — Privacy/access:** open `/host/rooms/<id>/settings`, change Invite-only/Locked/Subscriber/Verified/Ticket settings, save, reload, and confirm values persist. Use a second account that does not satisfy the restriction and verify backend room/RTC access is denied as applicable.
- [ ] **PH06-QA-006 — Schedule local timezone:** create a scheduled room using a local date/time. Reload `/host/schedule` and confirm the displayed date/time is the same local instant. Check the event from a browser/device configured to another timezone and confirm the same instant is automatically converted to that viewer's local timezone.
- [ ] **PH06-QA-007 — Schedule edit/lifecycle:** edit a scheduled room's date/time and confirm persistence. Start it and confirm a linked canonical live room is created/reused. Verify Pause, Resume, Open Host Room and End operate. Restart the same linked room where allowed and confirm repeated Start does not create duplicate linked rooms.
- [ ] **PH06-QA-008 — Host microphone/speaker mode:** from the website Host live room, click Start Speaking and verify the host microphone publishes to a separate listener. Mute and unmute locally and confirm audio state follows the control.
- [ ] **PH06-QA-009 — Raised-hand stage flow:** a listener raises a hand. Confirm it appears in Host controls. Approve the listener, confirm the listener receives speaker authority and Start Speaking becomes usable. Repeat with Reject and confirm the rejected user remains audience.
- [ ] **PH06-QA-010 — Host mute/remove:** with an approved speaker actively publishing, host clicks Mute. Confirm host UI shows muted state and the speaker client immediately reflects `Muted by Host`/cannot republish. Host unmuting restores permission. Move the speaker to Audience and confirm publishing authority is removed.
- [ ] **PH06-QA-011 — Invite present listener:** with a listener already in the room, Host selects Invite to stage. Confirm the listener receives the speaker invitation/authority flow and can become a speaker only through the authoritative RTC transition.
- [ ] **PH06-QA-012 — Invite person to restricted room:** configure the room as Invite-only/Locked. In Host controls search for a normal USER/CREATOR who is not present and invite them. Confirm Admin/Super Admin/Moderator identities are not offered as consumer invite candidates. Sign in as the invited account and verify access is granted according to backend room invitation authority.
- [ ] **PH06-QA-013 — Poll:** while LIVE, Host creates a poll. Confirm listeners see it without page reload, can vote, vote counts update, and Host can stop it. While PAUSED, confirm poll interaction controls are disabled.
- [ ] **PH06-QA-014 — Quiz:** while LIVE, Host creates & starts a quiz. Confirm listeners see the active question, can submit an option, receive the backend result, and Host can end the quiz. While PAUSED, confirm answering/creation controls are disabled.
- [ ] **PH06-QA-015 — Pause authority regression:** pause the broadcast with an existing raised hand and active listeners. Confirm listeners cannot send room chat, reactions, raise a new hand, vote/answer interactive content, or publish audio; Host cannot approve/reject/invite/mute/remove stage users while paused. Resume and confirm allowed interactions recover.
- [ ] **PH06-QA-016 — End realtime regression:** end from Host controls. Confirm all listener clients are notified immediately, RTC/audio cleanup runs, listener clients redirect to `/rooms` with the ended notification, and the Host returns to `/host/rooms`.
- [ ] **PH06-QA-017 — Bounded room chat regression:** generate enough messages to exceed the visible chat area. Confirm the room page height does not grow indefinitely; chat remains internally scrollable and own/other message presentation remains intact.
- [ ] **PH06-QA-018 — Creator/Admin preservation:** smoke-test Creator Studio room management/schedule/live console and Admin login/dashboard after PH06. Confirm PH06 website additions did not replace or reroute those applications.
